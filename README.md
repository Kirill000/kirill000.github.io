# kirill000.github.io

Как это работает
Этот простой инструмент для рисования позволяет сразу приступить к творчеству. Вот его основные возможности:

Рисование мышью или пальцем: Просто зажмите левую кнопку мыши (или коснитесь экрана) и ведите курсором. Линия будет плавной благодаря скруглению концов.

Выбор цвета: Нажмите на цветной круг в панели, чтобы открыть палитру и выбрать любой оттенок.

Регулировка толщины: Перетащите ползунок, чтобы изменить размер кисти от 1 до 50 пикселей. Текущее значение отображается рядом.

Очистка холста: Нажмите кнопку «Очистить», чтобы залить холст белым и начать заново.

Код уже адаптирован для работы на сенсорных экранах, так что рисовать можно и на планшете, и на телефоне.
